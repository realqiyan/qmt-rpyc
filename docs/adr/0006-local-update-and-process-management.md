# 本机原环境升级与用户级进程管理

客户端和服务端命令各自升级本机现有 Python 环境中的 `qmt-rpyc`，服务端增加当前用户的后台进程管理；一个 Python 环境只管理一个服务实例。升级前停止正在运行的服务，升级后仅输出下一步推荐命令，不自动启动服务，因此也允许显式降级到尚不支持后台管理的旧版本。该方案延续个人 QMT 部署方式，避免为软件升级引入 Windows 系统服务或独立版本环境切换，也不要求通过旧业务 RPC 执行本机管理。

原环境升级不提供自动回滚；停机先等待在途任务完成，超时取消升级并恢复接收请求，不默认强杀。升级通过新进程验证安装版本和命令加载，不以启动服务、RPC 就绪或 QMT 连接恢复为成功条件；完整行为见[本机软件升级命令](../design/software-update.md)。
