# 完整 QMT 的下载接口采用兼容空实现

用户确认目标完整 QMT 自身负责自动下载，允许下载接口采用空实现以兼容现有调用流程。BigQMT 适配器的历史行情、财务、板块和指数权重四类下载均不再发起底层调用，仍通过现有任务管理器创建独立 TaskRef 并查询任务状态；不伪造数据覆盖、下载进度或新鲜度。

这是新适配器明确约定的来源语义差异：completed 只表示兼容请求处理完毕，而不是一次实际下载调用已经完成。调用方仍须通过数据查询判断结果，不能把兼容下载当作刷新屏障；参数范围也不会被用于驱动同步。原 xtquant 适配器继续调用真实下载入口，公共操作集合、模型和契约指纹不因该来源差异改变。

该例外由用户明确授权，不能据此将缺失的读取字段或交易执行替换成空成功。新适配器装配时需在相关 capabilities 的 reason 中说明兼容空实现，并在服务端日志保留此含义。
